## 1. Executive Summary

이번 주의 최우선 이슈는 **2026-11-17 Microsoft Agent Framework의 공식 PyPI 패키지 공급망 침해**다. agent-framework 1.26.1 및 1.26.2에 자격증명 수집 코드가 포함되었으며 패키지가 격리되었다. Python의 site-packages 시작 훅(.pth)을 이용하므로 패키지를 import하지 않아도 영향을 받을 수 있다. ACB·CI·개발자 환경에서 해당 두 버전 설치 여부를 확인해야 한다. 현재 사용자 환경이 감염되었다는 증거는 없다.

공식 GitHub 릴리스 기준으로 LangGraph 1.2.24(11/20), CrewAI 1.15.44(11/19), OpenHands 1.43.0(11/20), Agno 3.2.1(11/17), LiveKit Agents 1.8.13(11/18), browser-use 1.0.8(11/22) 등 업데이트를 확인했다. 특정 기능 수정이 사업 요구사항을 충족하는지는 각 프로젝트별 회귀시험이 필요하다.

지난 호(11/19)의 중요한 정정: **Flowise는 2026-07-29 개발 종료를 공지했고 2026-08 저장소가 아카이브되었다.** W47의 신규 PoC 후보에서 제외하고 Langflow 또는 Dify로 대체한다. 이는 이번 주 새로 발생한 사건이 아니라 **지난 호에서 누락된 과거 사실을 새롭게 검증한 수정**이다. Microsoft AutoGen은 이미 지난 호에서 아카이브 사실을 반영했으며 이번 주 새 소식이 아니다.

### 이번 주 권고

## 3. 가장 먼저 살펴볼 상위 5개

### 1위 — LangGraph: 상태 기반 작업 오케스트레이션

- **기능:** 상태 그래프, 실행 중단 후 재개, 승인 절차, 도구·모델을 연결한 복구 가능한 프로세스.
- **공개 코드:** MIT, GitHub 45,269 stars, 11/22 UTC 저장소 push. 최신 확인 릴리스 1.2.24(11/20).
- **가격:** OSS 라이브러리 자체는 라이선스 사용료 없음. 모델·데이터 저장·배포 및 LangSmith 상용 기능은 별도.
- **장점:** SyncShift 장기 실행, ACB 작업 흐름, 승인/재시도/체크포인트에 적합.
- **주의:** 서비스 간 메시지 전송 규약이나 보안 체계를 대신하지 않음. 저장소 스키마 변경과 중복 부작용 방지가 필요.
- **대안:** CrewAI(역할 중심), Agno(가벼운 에이전트), 직접 구현한 워크플로 엔진.
- **우선 검증:** 체크포인트 강제 중단/복구 100회, side-effect exactly-once에 준하는 멱등성, 작업 취소·재시도.

### 2위 — Ollama: Mac Studio 로컬 추론 API

- **기능:** 로컬 모델 다운로드·서빙 및 HTTP 추론 엔드포인트.
- **공개 코드:** MIT, GitHub 187,882 stars, 11/22 UTC push.
- **가격:** 로컬 OSS 런타임 무료. 실제 비용은 하드웨어·전력·모델 저장·운영시간. 별도 클라우드 이용료는 계약 기준.
- **장점:** Mac Studio M4 Max 64GB에서 외부 전송 없는 배치·개발 추론 구성 가능.
- **주의:** 기존 OpenWebUI/LiteLLM/Qwen 기반 스택과 중복 도입 가능성. 모델의 상업적 사용 권한은 각 모델 라이선스를 따로 확인.
- **대안:** MLX/MLX-LM, llama.cpp, 기존 로컬 추론 서버.
- **우선 검증:** 동일 모델·양자화·프롬프트로 TTFT, 출력 tokens/s, 동시성 1/2/4, 메모리 최고점, 24시간 안정성 비교.

### 3위 — OpenHands: 격리형 코딩 에이전트 실험

- **기능:** 코드 탐색·편집·명령 실행 및 수정 검증을 연결하는 코딩 에이전트.
- **공개 코드:** MIT, GitHub 94,079 stars, 11/22 UTC push; v1.43.0(11/20).
- **가격:** OSS 자가호스팅 코드 무료. 모델 호출·실행 컨테이너·상용 클라우드 사용료는 별도; 공식 서비스 현재 요금 상세는 미확인.
- **장점:** SyncShift의 OpenRewrite 전후 오류 수정과 회귀 실패 원인 분석에 적합.
- **주의:** 명령·네트워크·파일 접근의 위험. 원본 저장소에 직접 쓰기 금지; 승인된 브랜치와 격리 런타임에서만 실행.
- **대안:** OpenAI Codex CLI(Apache-2.0), Continue(Apache-2.0), Aider, OpenCode(라이선스·버전 별도 확인).
- **우선 검증:** 10개 레거시 변경 예제, 컴파일 성공률·테스트 통과율·수동 수정량·비용 측정.

### 4위 — Langfuse: 추적, 평가 및 운영 관측

- **기능:** 프롬프트·모델 호출 trace, 점수·회귀평가, 비용과 실행 성능의 계측.
- **공개 코드:** GitHub 37,724 stars, 11/22 UTC push. **기본 코드 MIT, ee/ 등은 별도 상용 라이선스**(저장소 전체를 MIT로 단정하면 안 됨).
- **가격:** OSS 자가호스팅 무료(인프라 별도). 클라우드 Hobby 무료, 상위 요금은 이벤트/trace 볼륨별 변동; [공식 가격표](https://langfuse.com/pricing-self-host) 참고.
- **장점:** 로컬·외부 모델을 동일 기준으로 비교하고 ACB 경로별 실패를 추적.
- **주의:** 수집 trace에 프롬프트·개인정보·비밀키가 저장될 수 있음. 민감정보 마스킹·보존기간 정책 선행.
- **대안:** LangSmith, Arize Phoenix, AgentOps, OpenTelemetry 직접 구성.
- **우선 검증:** 세션·에이전트·도구 호출 span 연결, 오류 분류, 평가 점수와 비용 대시보드.

### 5위 — LiveKit Agents: 실시간 음성 AI 전송 계층

- **기능:** WebRTC/음성 세션에 STT·LLM·TTS 파이프라인 결합, 실시간 인터럽트·상태 처리.
- **공개 코드:** Apache-2.0, GitHub 15,302 stars, 11/21 UTC push; v1.8.13(11/18).
- **가격:** OSS 직접 운영은 인프라 비용. LiveKit Cloud Build $0/월, Ship $50/월부터, Scale $500/월부터이며 세션·추론·STT/TTS 종량 비용 가능(11/23 공식 가격표).
- **장점:** Basic Portal 음성 회의록 및 Home Assistant Voice 연동의 재사용 가능한 미디어 계층.
- **주의:** 음성 인식 정확도, 한국어 TTS, 화자분리 품질은 별개 문제. 외부 서비스 전송·보존과 전화 기능 지역 제약 확인.
- **대안:** 직접 WebRTC + faster-whisper/MLX, Pipecat, Vocode.
- **우선 검증:** 한국어 명령/회의 음성 WER, 응답 왕복 p95, 인터럽트 성공률, 화자별 분리 정확도.

## 5. P0: Microsoft Agent Framework 공급망 사고 대응

**확인된 사실** — 2026-11-17 20:35 UTC 악성 1.26.1, 21:08 UTC 악성 1.26.2 업로드. 둘 다 PyPI 격리됨. 악성 wheel의 .pth 훅은 site-packages를 로드하는 Python 시작 시 실행 가능하다. AWS/Azure/GitHub 및 CI/CD 관련 토큰·비밀정보 수집을 시도한다. **2026-11-12의 1.26.0이 당시 마지막 정상 버전**이었다. 이는 Microsoft 공식 소스 전체가 변조되었다는 의미가 아니며, 사용자의 ACB 환경이 노출되었다는 사실도 아직 없다.

**검사·조치 절차:**

1. 개발자 Mac Studio, 테스트/배포 컨테이너, GitHub Actions 및 종속성 lockfile에서 정확히 **agent-framework==1.26.1 또는 1.26.2** 설치 이력을 조사한다. 가상환경마다 site-packages 경로를 구분한다.
2. 해당 버전이 발견되면 먼저 **격리**한다. 감염 의심 환경에서 pip·pytest 등 Python 실행도 훅을 재발동시킬 수 있으므로 정상 컴퓨터의 포렌식 방식으로 조사한다.
3. 오염된 runner·이미지·가상환경은 깨끗한 원본으로 재빌드한다. 환경에서 접근 가능했던 GitHub 토큰, 클라우드 자격증명, LLM API Key, CI OIDC 설정 및 비밀키를 회수·교체하고 감사 로그를 검토한다.
4. 안전한 패키지 정확 버전과 해시, SBOM, 아티팩트 서명, 격리된 CI runner, 최소 권한·에그레스 제한을 채택한다.
5. Microsoft Agent Framework의 신규 PoC는 패키지 발행 경로 안전성 확인 이후 재개한다. **의심 버전을 정상버전으로 다운그레이드하는 것만으로 이미 노출된 비밀정보 문제가 해결되지는 않는다.**

원문: [Wiz 사건 분석 11/17](https://www.wiz.io/blog/malicious-version-of-microsofts-agent-framework-published-to-pypi), [StepSecurity 역분석 11/18](https://www.stepsecurity.io/blog/microsoft-agent-framework-pypi-package-compromised). 유출된 자격증명 범위, 공격자 전체 행동, Microsoft 최종 근본 원인 분석은 **추가 검증 필요**다.

## 6. 기존 프로젝트 적용성 및 우선순위

### A. ACB — TypeScript Core / Rust Agent Runtime

- **P0**: 에이전트 런타임의 패키지 설치 경로 점검. Python 기반 에이전트 연결 중 악성 agent-framework 두 버전이 있는지 먼저 확인.
- **P1**: A2A는 agent-to-agent 작업 교환 참고, MCP는 tool/resource 호출 참고. 둘은 서로 대체재가 아니다. 기존 ACB 브리지를 바로 Microsoft 프레임워크로 교체하지 않는다.
- **설계:** trace_id / agent_id / task_id / idempotency_key, 메시지 서명, 권한 주체 위임, 타임아웃, 리트라이 상한, 작업 재시작·체크포인트, DLQ, 감사 로그.
- **합격:** 1,000건 메시지 전송에서 누락/중복 부작용 0건, 연결 단절·중복 전송·순서 뒤바뀜 시험 통과. 실험 기준이며 측정 결과가 아님.
- **후보:** LangGraph 상태 관리 + 자체 신뢰성 전송 + A2A/MCP 어댑터.

### B. SyncShift — 레거시 코드 현대화

- **P1**: OpenRewrite 레시피로 기계적으로 가능한 JDK·Spring·DB SQL 규칙 변환. 그 뒤 OpenHands/Codex를 제한된 작업 브랜치에서 컴파일 실패 수정용으로 비교.
- **절차:** 샘플 프로젝트 복제 → baseline build/test → 레시피 적용 → 변경 diff → 에이전트 보완 → 정적 검사·라이선스 검증 → DVT/CVT 성격의 회귀 평가 → 수동 승인 PR.
- **합격:** 빌드 성공률, 회귀 테스트 통과율, 의미 보존, 수정당 사람 검토시간, 외부 코드 전송량.
- **금지:** 생산 코드 자동 Push/배포·비밀키 접근 허용·실패 결과를 성공으로 간주.

### C. Mac Studio M4 Max 64GB — 로컬 LLM

- **P1/P2**: 기존 OpenWebUI·LiteLLM·Qwen 계열을 기준으로 Ollama, MLX-LM, 현행 서빙 경로를 비교하고 가장 낮은 운영 비용과 가장 높은 정합성을 선택. 모든 프레임워크를 중복 상주시킬 필요 없음.
- **실험:** 동일 8K/16K/32K 컨텍스트, 동일 양자화, 동시 요청 1/2/4, 한국어 도구 호출 50개, JSON schema 준수율, TTFT·tokens/s·p95·peak RAM 측정.
- **주의:** 64GB 통합 메모리의 실제 모델별 RAM은 별도 측정 필요. 클라우드 호출·원격 telemetry가 정말 차단되었는지 프록시 경로에서 검증.

### D. Basic Portal — 사내 AI 업무 포털

- **P1**: 내부 위키 검색 및 회의록 요약을 첫 표준 시나리오로 삼고 평가용 golden set 작성. 문서별 ACL을 검색 결과에서 재검증하는 RAG 구성.
- **UI 선택:** 개발자 중심 스트리밍 UI는 Vercel AI SDK, 비개발자 워크플로 PoC는 Langflow, Dify는 사용 형태별 라이선스 법무 검토 후 채택. Flowise 신규 도입 제외.
- **저장·관측:** Mem0는 사용자 단위 기억·삭제·격리 테스트가 통과할 때만. Langfuse trace는 개인정보/기밀 마스킹.
- **합격:** 미인가 문서 0건 노출, 근거 없는 답변 비율 감소, 회의록 액션 아이템 재현율 측정.

### E. 음성 AI / Home Assistant Voice

- **P2**: LiveKit Agents로 대화 세션의 WebRTC/반응성을 테스트하고 STT는 한국어 성능을 별도 비교(Qwen 계열 ASR, Whisper/MLX 등). 화자 분리는 별도 평가.
- **합격:** 50개 한국어 명령·10개 다자간 회의 녹음의 WER/DER, 턴 종료~응답 첫 음성 p50/p95, 인터럽트 처리율, 음성 데이터 보존/전송 검증.
- **비용:** 로컬 추론 전력·대기 비용 vs 외부 STT/TTS API 분당 비용을 동일 음성량으로 평가.

## 7. 4단계 현장 도입 가이드 (코드 변경 전 검증)

| 단계 | 실행 범위 | 산출물 | 진행 조건 |
|---|---|---|---|
| 1. 보안/인벤토리 | pip·npm·Docker 이미지, lockfile, 사용자별 접근권한 조사 | 패키지/SBOM 및 사고 노출 판단표 | P0 완료 |

## 9. 검증된 주장과 미검증 항목

**공식 자료로 확인:** Microsoft PyPI 침해의 두 버전·일시·기법(보안 연구기관 독립 분석), 각 주요 공식 릴리스의 게시 시점, GitHub API의 프로젝트 stars/라이선스/최종 push, Flowise sunset, Dify·Langfuse의 라이선스 세부, LiveKit·E2B 공식 요금, Mem0 소스 문서의 신규 과금 규칙.

**추가 검증 필요:** Microsoft 내부 계정 침해의 최종 원인과 영향받은 개발자 범위, 모든 패키지의 재현 가능한 SBOM·취약점, browser-use의 현재 클라우드 요금, E2B 실제 격리 설정/네트워크 정책, 코딩 에이전트의 벤치마크 성능, Mac Studio 모델별 처리량, 로컬 STT/화자분리의 한국어 정확도, 모든 프로젝트의 장기 SLA, A2A/ACB 상호운용 실증, 이번 주에 처음 공개된 '신생 프로젝트' 전수 조사.

**원문 검토 원칙:** [kiosa 원문](https://x.com/thegreatest_sv/status/2080634616860320073) 및 [awesome-ai-agents](https://github.com/slavakurilyak/awesome-ai-agents)는 후보 탐색용이다. 나열된 항목을 공식 인증/성능 비교 결과로 간주하지 않는다. '300+ 검증 완료' 등의 광고성 표현을 별도 실측 없이 채택하지 않는다.
