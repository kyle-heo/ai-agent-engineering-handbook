## 핵심 요약

에이전트는 모델 추론, 오케스트레이션, 도구 호출, 메모리, 실행 격리, 관측 및 평가로 구성되는 기술 스택이다. 오픈소스 후보는 인기뿐 아니라 유지보수, 라이선스, 성능 및 운영 위험으로 평가해야 한다.

## 우선 검토할 다섯 프로젝트

1. [Ollama](https://github.com/ollama/ollama) — 로컬 추론
2. [LangChain](https://github.com/langchain-ai/langchain) — LLM 애플리케이션
3. [Open Interpreter](https://github.com/OpenInterpreter/open-interpreter) — 로컬 코드 실행
4. [AutoGen](https://github.com/microsoft/autogen) — 멀티 에이전트 (현재 유지보수 상태 재검증 필요)
5. [Aider](https://github.com/Aider-AI/aider) — Git 기반 코딩 보조

## 도입 검토

- 통신: 에이전트 간 메시지 전달 및 복구
- 코드 현대화: 상태 복원, 코드 변환, 자동 검증
- 업무 포털: 접근 제어, 메모리, 워크플로
- 음성: 한국어 인식 정확도, 지연, 비용
